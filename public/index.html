Your studio setup

Free automatic subtitles

Choose Free local subtitles + transcript excerpts. English speech recognition runs on this computer without an API key or API charges. Processing can take several minutes. Clips use transcript excerpts without AI moment ranking.

Paid AI selection

Use Start with AI.cmd in the app folder. It asks for your OpenAI API key in a hidden local prompt. The key stays in the server process and is never sent to this page.

If the app is already running, close it using Stop Cutroom.ps1 first. AI processing uses your OpenAI API account and may incur charges.

Try it without an API key

Choose Use my English subtitles, then upload an MP4 and its matching SRT file. Cutroom makes real captioned clips using transcript excerpts. This mode does not use AI to pick moments.

What this version includes

Local project history, background processing, adjustable horizontal crop, burned-in captions, MP4 and SRT downloads. Keep the local server running while clips render.

Accounts, payments, link imports and automatic face tracking are not part of this first version.

Caption style

Colours keep a dark outline for readability. Styles are included in MP4 exports; SRT downloads contain plain text.
